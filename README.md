# Pi-Hole DNS Server (Nov-2025)
Pi-hole is a **Linux network-level application** that acts as a **DNS sinkhole** for your private network. When configured as your network's DNS server (replacing your router's or ISP's default), it offers several powerful capabilities:

- 🚫Network-Wide Content Blocking
- 🚀 Performance and DNS Features
- 🖥️ Management and Monitoring
## Hardware Used
> Any Raspberry Pi model should be fine
- Raspberry Pi 3 B+
> A 32 GB or more micro SD card is recommended
- Sandisk Micro SD Card 64 GB 
## Required Downloads
- [Raspberry Pi Imager](https://www.raspberrypi.com/software/)
> 64 bit OS is recommended for more modern Pi models
- [Raspberry Pi OS](https://www.raspberrypi.com/software/operating-systems/)
